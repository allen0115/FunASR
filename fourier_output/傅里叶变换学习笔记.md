## 1. 正弦波叠加合成方波

### 生活类比：煮粥

- 每一勺米 = 一个正弦波
- 锅 = 时间轴
- 粥的高度 = 合成后的波形

一勺米：表面凹凸不平 ← 一个正弦波
三勺米：凹凸程度变平缓 ← 三个正弦波叠加
十勺米：接近水平 ← 十个正弦波叠加
一百勺米：几乎完美水平 ← 一百个正弦波叠加

### 方波的傅里叶级数公式

```
square(t) = (4/π) × Σ[sin((2n-1)ωt) / (2n-1)]  n=1,2,3,...
```

### 关键规律

| 正弦波 | 频率 | 幅度 | 作用 |
|--------|------|------|------|
| 第 1 层 | 最低 | 最大 | 决定方波的**基本形状** |
| 第 3 层 | 3 倍 | 1/3 | 让方波**边缘变陡** |
| 第 5 层 | 5 倍 | 1/5 | 让方波**顶部变平** |
| 第 N 层 | N 倍 | 1/N | **精细修正** |

### 核心思想

> 方波 = 一堆正弦波堆出来的"近似平的东西"
> 就像把一堆波浪很高的糖堆成一个近似正方体，波浪越多，正方体越精确。

## 2. 波叠加的含义

### 一句话理解

**波叠加 = 同一位置的高度相加**

### 数学表达

```
叠加波(t) = 波1(t) + 波2(t)
```

### 两个正弦波叠加示例

```
位置:      1    2    3    4    5    6    7    8
绳子1高度: 0    1    0   -1    0    1    0   -1
绳子2高度: 0    1    0   -1    0    1    0   -1
─────────────────────────────────────────────
叠加高度:  0    2    0   -2    0    2    0   -2
```

叠加后波形变高了。

## 3. 频率探测：乘法 vs 加法

### 核心区别

| 操作 | 目的 | 含义 |
|------|------|------|
| **加法** | 合成信号 | 把多个频率**混在一起** |
| **乘法** | 探测频率 | 判断某个频率**是否存在** |

### 破案类比

**加法**的做法：
```
信号 = 嫌疑人A(3Hz) + 嫌疑人B(5Hz) + 嫌疑人C(7Hz)
→ 混合后无法知道 3Hz 是否在里面
```

**乘法**的做法：
```
信号 × 3Hz的"身份证" = ?
→ 核对结果有规律 → 3Hz在里面！
→ 核对结果杂乱无章 → 3Hz不在里面！
```

### 信号处理类比

| | 加法 | 乘法 |
|---|---|---|
| **目的** | 合成信号 | 探测频率 |
| **类比** | 把不同颜色颜料倒在一起 | 用滤镜过滤出特定颜色 |
| **信息处理** | 混合（不可逆） | 筛选（可判据） |

### 生活中的乘法筛选

- **收音机选台**：所有电台混合在空气中（加法），调台是乘法筛选
- **音乐均衡器**：音乐是多频率混合（加法），调低音增益是乘法筛选

## 4. 乘法探测法的数学推导

### 核心问题

为什么 `信号 × 某频率正弦波` 的均值 = 0，说明信号不包含该频率？

### 情况一：信号包含探测频率

假设信号包含 3Hz：
```
f(t) = sin(2π×3t) + 其他频率
```

用 3Hz 探测：
```
探测结果 = f(t) × sin(2π×3t)
         = sin²(2π×3t) + 其他×sin(2π×3t)
         = ↑ 第一部分        ↑ 第二部分
```

**第一部分**（同频率相乘）：
```
sin²(2π×3t) = [1 - cos(2π×6t)] / 2
            = 1/2 - cos(2π×6t)/2
```
- `1/2` 是常数项，均值 = 1/2
- `-cos(2π×6t)/2` 是高频震荡，均值 = 0
- **第一部分均值 = 1/2 ≠ 0**

**第二部分**（不同频率相乘）：
- 不同频率相乘 → 全是正负对称的震荡项 → 均值 = 0

**结论**：包含时，探测均值 ≠ 0

### 情况二：信号不包含探测频率

假设信号不含 3Hz：
```
f(t) = sin(2π×5t) + sin(2π×7t)
```

用 3Hz 探测：
```
探测结果 = sin(2π×5t)×sin(2π×3t) + sin(2π×7t)×sin(2π×3t)
```

每一项都是不同频率相乘 → 全是震荡项 → 均值 = 0

**结论**：不包含时，探测均值 = 0

### 总结对比

| 情况 | 数学本质 | 均值结果 |
|------|---------|---------|
| 信号包含探测频率 | sin²(ωt) 展开后有常数项 1/2 | ≠ 0 |
| 信号不包含探测频率 | 不同频率相乘，全是震荡项 | = 0 |

## 5. sin²(θ) = [1 - cos(2θ)] / 2 的推导

### 推导步骤

**第一步**：余弦二倍角公式
```
cos(2θ) = cos²(θ) - sin²(θ)
```

**第二步**：代入 cos²(θ) = 1 - sin²(θ)
```
cos(2θ) = [1 - sin²(θ)] - sin²(θ)
        = 1 - 2·sin²(θ)
```

**第三步**：整理出 sin²(θ)
```
2·sin²(θ) = 1 - cos(2θ)
sin²(θ) = [1 - cos(2θ)] / 2
```

**第四步**：令 θ = 2π×3t
```
sin²(2π×3t) = [1 - cos(2×2π×3t)] / 2
             = [1 - cos(2π×6t)] / 2
```

### 关键结论

```
sin²(ωt) = [1 - cos(2ωt)] / 2
         = 1/2 - cos(2ωt)/2
           ↑        ↑
         常数项   高频震荡项
```

- **1/2**：常数项，均值就是 1/2
- **-cos(2ωt)/2**：高频震荡项，均值 = 0

所以 sin²(ωt) 的均值 = **1/2** ≠ 0

## 6. 正弦波均值为 0 的证明

### 几何直觉

正弦波上下对称，正面积 = 负面积，所以均值为 0。

### 定积分计算

```
均值 = (1/2π) × ∫₀²π sin(t) dt
```

#### 详细计算过程

**第一步**：确定原函数

```
d/dt [cos(t)] = -sin(t)
→ sin(t) 的原函数是 -cos(t)
```

**第二步**：写出定积分公式

```
∫₀²π sin(t) dt = [-cos(t)]₀²π
```

**第三步**：代入上下限

```
= [-cos(2π)] - [-cos(0)]
```

**第四步**：计算 cos 值

```
cos(2π) = cos(360°) = 1
cos(0) = cos(0°) = 1
```

**第五步**：计算

```
= (-1) - (-1)
= -1 + 1
= 0
```

### 离散数值验证

| 位置 t | sin(t) | 值 |
|--------|--------|-----|
| 0 | sin(0) | 0 |
| π/4 | sin(π/4) | +0.707 |
| π/2 | sin(π/2) | +1.0 |
| 3π/4 | sin(3π/4) | +0.707 |
| π | sin(π) | 0 |
| 5π/4 | sin(5π/4) | -0.707 |
| 3π/2 | sin(3π/2) | -1.0 |
| 7π/4 | sin(7π/4) | -0.707 |

求和：0 + 0.707 + 1.0 + 0.707 + 0 + (-0.707) + (-1.0) + (-0.707) = **0**

### 关键前提

必须取**整数个完整周期**，正负才能完全抵消。

## 7. d/dt [cos(t)] = -sin(t) 的推导

### 导数定义

```
f'(t) = lim (h→0) [f(t+h) - f(t)] / h
```

### 推导过程

**第一步**：代入 f(t) = cos(t)

```
cos'(t) = lim (h→0) [cos(t+h) - cos(t)] / h
```

**第二步**：用余弦加法公式展开

```
cos(t+h) = cos(t)·cos(h) - sin(t)·sin(h)

cos'(t) = lim (h→0) [cos(t)cos(h) - sin(t)sin(h) - cos(t)] / h
```

**第三步**：整理

```
= lim (h→0) [cos(t)·(cos(h)-1)/h - sin(t)·sin(h)/h]
```

**第四步**：求两个极限

```
lim (h→0) sin(h)/h = 1          ← 小角度近似
lim (h→0) (cos(h)-1)/h = 0      ← 用二倍角公式证明
```

**第五步**：代入结果

```
cos'(t) = cos(t)·0 - sin(t)·1 = -sin(t)
```

### 几何直觉

从 cos(t) 图像看斜率变化：

```
cos(t):
  1 ┤╱╲      ╱╲
    │  ╲    ╱  ╲
    │    ╲╱    ╲
  0 ┤────────────╲────
    │             ╲
 -1 ┤               ╲
    └──────────────────→ t
     0   π/2  π  3π/2 2π
```

- t=0：cos(t) 下降，斜率为负 → -sin(0) = 0（极值点切线水平）
- t=π/2：cos(t) 最陡地下跌 → -sin(π/2) = -1
- t=π：cos(t) 从降转升，斜率为零 → -sin(π) = 0
- t=3π/2：cos(t) 最陡地上升 → -sin(3π/2) = 1

## 8. 傅里叶变换与 FunASR 的关系

```
时域波形 → [傅里叶变换] → 频域频谱 → [梅尔滤波器组] → fbank 特征 → 送入模型
```

### 对应关系

| 傅里叶概念 | FunASR 应用 |
